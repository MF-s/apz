## Тест-кейси (Test Cases)

### Тест-кейс: TC-101. Авторизація зареєстрованого користувача
**Пріоритет:** High (Високий)
**Тип:** Positive (Позитивний)
**Компонент:** Login Module  
**Пристрій:** Смартфон (Android/iOS) / Web Browser  

| Поле | Опис |
| :--- | :--- |
| **Передумови (Pre-conditions)** | 1. Додаток/сайт відкрито.<br>2. Користувач вже зареєстрований із логіном testuser@rozetka.ua та паролем Password123.<br>3. Пристрій підключено до інтернету. |
| **Кроки (Steps)** | 1. Натиснути на кнопку «Увійти» на головному екрані.<br>2. У поле «Email або телефон» ввести testuser@rozetka.ua.<br>3. У поле «Пароль» ввести Password123.<br>4. Натиснути кнопку «Увійти». |
| **Очікуваний результат (Expected Result)** | 1. Відбувається успішна авторизація.<br>2. Здійснюється перехід до особистого кабінету або на головну сторінку.<br>3. Відображається ім'я користувача у профілі. |
| **Постумови (Post-conditions)** | Користувач авторизований у системі, сесія активна. |
