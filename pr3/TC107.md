### Тест-кейс: TC-107. Успішне оформлення замовлення з самовивозом
**Пріоритет:** High (Високий)  
**Тип:** Positive (Позитивний)  
**Компонент:** Checkout Module  
**Пристрій:** ПК / Web Browser  

| Поле | Опис |
| :--- | :--- |
| **Передумови (Pre-conditions)** | 1. Користувач авторизований.<br>2. У кошику є товар у наявності. |
| **Кроки (Steps)** | 1. Перейти в кошик та натиснути «Оформити замовлення».<br>2. Ввести контактні дані отримувача (ПІБ, телефон).<br>3. Спосіб доставки обрати: «Самовивіз з точки видачі Rozetka».<br>4. Обрати зі списку найближчу точку видачі.<br>5. Спосіб оплати обрати: «Оплата під час отримання товару».<br>6. Натиснути кнопку «Замовлення підтверджую». |
| **Очікуваний результат (Expected Result)** | 1. Замовлення успішно створюється.<br>2. Відкривається сторінка подяки з номером замовлення (наприклад, № 782 910 112).<br>3. На вказаний номер/email надходить підтвердження замовлення. |
| **Постумови (Post-conditions)** | Замовлення збережено в базі зі статусом «В обробці». |
