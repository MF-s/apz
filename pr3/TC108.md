### Тест-кейс: TC-108. Оформлення замовлення без заповнення обов'язкових полів (ПІБ)
**Пріоритет:** High (Високий)  
**Тип:** Negative (Негативний)  
**Компонент:** Checkout Module  
**Пристрій:** ПК / Web Browser  

| Поле | Опис |
| :--- | :--- |
| **Передумови (Pre-conditions)** | Товар додано в кошик, відкрита сторінка «Оформлення замовлення» для неавторизованого користувача. |
| **Кроки (Steps)** | 1. Залишити порожнім поле «Прізвище та ім'я».<br>2. Заповнити поле «Телефон» коректним номером.<br>3. Обрати доставку та спосіб оплати.<br>4. Натиснути кнопку «Замовлення підтверджую». |
| **Очікуваний результат (Expected Result)** | 1. Замовлення НЕ створюється.<br>2. Поле «Прізвище та ім'я» підсвічується червоним кольором.<br>3. З'являється повідомлення про помилку: «Заповніть це поле» або «Вкажіть прізвище та ім'я». |
| **Постумови (Post-conditions)** | Користувач залишається на сторінці Checkout до виправлення помилок. |
