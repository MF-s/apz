### Тест-кейс: TC-102. Пошук товару за ключовим словом
**Пріоритет:** High (Високий)  
**Тип:** Positive (Позитивний)  
**Компонент:** Search Module  
**Пристрій:** ПК / Web Browser  

| Поле | Опис |
| :--- | :--- |
| **Передумови (Pre-conditions)** | 1. Головна сторінка сайту Rozetka відкрита.<br>2. Інтернет-з'єднання стабільне. |
| **Кроки (Steps)** | 1. Клікнути на текстове поле пошуку у верхній шапці сайту.<br>2. Ввести пошуковий запит «Ноутбук Lenovo».<br>3. Натиснути клавішу Enter або кнопку «Знайти». |
| **Очікуваний результат (Expected Result)** | 1. Відкривається сторінка з результатами пошуку.<br>2. У списку відображаються лише ноутбуки бренду Lenovo.<br>3. Кількість знайдених товарів більше 0. |
| **Постумови (Post-conditions)** | Користувач перебуває на сторінці результатів пошуку. |
