### Тест-кейс: TC-106. Видалення товару з Кошика
**Пріоритет:** Medium (Середній)  
**Тип:** Positive (Позитивний)  
**Компонент:** Cart Module  
**Пристрій:** ПК / Web Browser  

| Поле | Опис |
| :--- | :--- |
| **Передумови (Pre-conditions)** | У кошику додано 1 товар. |
| **Кроки (Steps)** | 1. Відкрити кошик.<br>2. Натиснути на контекстне меню (три крапки) або кнопку видалення (іконка кошика/хрестика) біля товару.<br>3. Вибрати пункт «Видалити». |
| **Очікуваний результат (Expected Result)** | 1. Товар зникає зі списку кошика.<br>2. Відображається порожній стан кошика (повідомлення «Кошик порожній»).<br>3. Загальна сума до сплати дорівнює 0 грн. |
| **Постумови (Post-conditions)** | Кошик порожній. |
